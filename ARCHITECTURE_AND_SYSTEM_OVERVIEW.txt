3. COMPLETE TECHNICAL ARCHITECTURE & STACK
================================================================================

A. Framework & Runtime:
   - Next.js 14 (App Router Architecture): Utilizes static site generation (SSG)
     and client-side hydration for maximum speed and SEO crawlability.
   - React 18: Powers the modular UI component model.
   - Node.js 20+ LTS: Execution runtime.

B. Programming Language:
   - TypeScript 5.5+: Strict typing enabled for component props, metadata,
     and state management, minimizing runtime bugs.

C. Styling & Presentation Layer:
   - Tailwind CSS 3.4: Utility-first CSS engine.
   - PostCSS & Autoprefixer: Automates vendor prefixing across all browsers.
   - Custom Glassmorphism: Custom backdrop filters, translucent surface cards,
     and dynamic CSS variables for mouse coordinates.
   - Fonts: Next.js Google Font optimization loading "Plus Jakarta Sans" 
     (primary geometric sans) and "JetBrains Mono" (technical code accents).

D. UI Primitives & Icons:
   - Lucide React (v0.460): Lightweight tree-shaken SVG icon library.
   - Custom Interactive Effects:
     * Dynamic coordinate spotlight tracking on feature cards (Magic UI style)
     * IntersectionObserver scroll-reveal hooks for smooth section entrance
     * Continuous CSS marquee animations for partner and technology trust badges

E. Hosting & Global Edge Network:
   - Vercel Cloud Platform: Global Edge CDN for sub-50ms TTFB across India & worldwide.
   - Automatic SSL / TLS certificates via Let's Encrypt / Vercel Edge.
   - Native HTTP/2 & HTTP/3 support.

8. SEO, SEARCH CONSOLE & CRAWLER ARCHITECTURE
================================================================================

- Next.js Metadata API (`app/layout.tsx`):
  Generates search-engine titles, descriptions, canonical URLs, and OpenGraph tags.
- Dynamic Sitemap (`app/sitemap.ts`):
  Emits `/sitemap.xml` with canonical priority 1.0 and weekly update frequency.
- Crawler Control (`public/robots.txt`):
  Configured to grant full indexing permission (`Allow: /`) to Googlebot,
  Bingbot, and major crawlers while advertising the official sitemap URL.
- Google Search Console Integration:
  Configured and verified under the root domain `https://www.famtrix.in/`.

9. DEPLOYMENT & CI/CD PIPELINE
================================================================================

Workflow:
1. Developer makes changes in local workspace (`d:/famtrix/famtrix-website`).
2. Changes committed with descriptive Git messages and pushed to GitHub
   repository (`https://github.com/Tinexit/Famtrix.git`, `main` branch).
3. Vercel GitHub Webhook immediately triggers an automated build:
   `npm run build` -> Next.js compiles static pages & chunks.
4. On build success (Exit Code 0), the new release is deployed atomically to
   Vercel's global CDN without downtime.

10. MAINTENANCE & FUTURE EXTENSIBILITY GUIDELINES
================================================================================

- Adding New Pages:
  Create a new folder under `app/<route-name>/page.tsx`. Remember to add the
  new route to `app/sitemap.ts` so Google automatically indexes it.
- Editing Services or Content:
  Update the service arrays in `app/page.tsx`.
- Form Integrations:
  Form submissions in `app/page.tsx` and `app/checklist/page.tsx` currently
  simulate API completion. To persist leads, connect the submit handlers
  to an email API (Resend, SendGrid) or a database (Supabase, Firebase, or MongoDB).
